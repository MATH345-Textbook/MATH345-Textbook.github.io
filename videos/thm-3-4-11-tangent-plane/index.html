Theorem 3.4.11. If f is differentiable at x-naught, y-naught, the tangent plane to its graph S exists, is unique, and has this equation. Here's why.

First, slice S with the plane y equals y-naught. The curve z equals f of x, y-naught has slope f sub x at x-naught, so its tangent line, r one, has direction vector one, zero, f sub x.

Similarly, slicing with x equals x-naught gives a tangent line, r two, with direction vector zero, one, f sub y.

Any tangent plane must contain both lines. So we want a normal vector n equals a, b, c, perpendicular to both direction vectors: a homogeneous system.

Its augmented matrix is already in reduced row echelon form, with a and b basic, and c free. Setting c equal to one gives the basic solution: n equals negative f sub x, negative f sub y, one.

So the tangent plane is n dot x minus x-naught, y minus y-naught, z minus f of x-naught, y-naught, equals zero. Solving for z gives the theorem's equation: the graph of the linear approximation L.
