Theorem 5.5.7. Two-variable second derivative test.

Let \(f:\R^2\to\R\) be twice continuously differentiable near a critical point \((a,b)\text{.}\) Define
\begin{equation*} D(a,b)=f_{xx}(a,b)f_{yy}(a,b)-f_{xy}(a,b)^2. \end{equation*}
🔗
  • If \(D(a,b)>0\) and \(f_{xx}(a,b)>0\text{,}\) then \((a,b)\) is a local minimum.
    🔗
    🔗
  • If \(D(a,b)>0\) and \(f_{xx}(a,b)\lt0\text{,}\) then \((a,b)\) is a local maximum.
    🔗
    🔗
  • If \(D(a,b)\lt0\text{,}\) then \((a,b)\) is a saddle point.
    🔗
    🔗
  • If \(D(a,b)=0\text{,}\) the test is inconclusive.
    🔗
    🔗
🔗

Why is this true?.

Apply Activity 5.5.8 to the Hessian matrix \(H_f(a,b)\text{,}\) then apply Theorem 5.5.5.
