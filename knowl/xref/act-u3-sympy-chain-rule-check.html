Activity 3.5.15. Checking the chain rule in SymPy (U3-LO6).
Revisit \(f(x,y)=3x^2-2xy+y^2\) and \(G(u,v)=(3u+2v,4u-v)\) from the preceding calculation. The code computes \(J_{f\circ G}\) in two ways: multiplying the Jacobian matrices and differentiating the composite expression directly. As in Activity 3.3.43, we put a scalar expression in a one-entry matrix to use .jacobian(). The command sp.simplify simplifies symbolic expressions, including the entries of a matrix.
🔗
import sympy as sp

x, y, u, v = sp.symbols("x y u v")
f = 3*x**2 - 2*x*y + y**2
G = sp.Matrix([3*u + 2*v, 4*u - v])

Jf = sp.Matrix([f]).jacobian([x, y])
JG = G.jacobian([u, v])
Jf_at_G = Jf.subs({x: G[0], y: G[1]})
chain = sp.simplify(Jf_at_G * JG)

f_of_G = f.subs({x: G[0], y: G[1]})
direct = sp.Matrix([f_of_G]).jacobian([u, v])

print(Jf_at_G.shape, JG.shape, chain.shape)
print(chain)
print(sp.simplify(direct - chain))
print(chain.subs({u: 1, v: 0}))

Solution.
  1. The outer function has one output and two inputs, so \(J_f(G(u,v))\) has shape \(1\times2\text{.}\) The inner map has two outputs and two inputs, so \(J_G\) has shape \(2\times2\text{.}\) Their product has shape \(1\times2\text{,}\) as required for the Jacobian of a scalar-valued function of \(u,v\text{.}\) The matrix \(J_G\) acts first on an input change; \(J_f(G(u,v))\) then acts on the intermediate change. The reversed product is undefined because its inner dimensions would be \(2\) and \(1\text{.}\)
    🔗
    🔗
  2. The input to the outer function is \(G(u,v)\text{,}\) so its derivative must be evaluated there. At \((u,v)=(1,0)\text{,}\) we have \(G(1,0)=(3,4)\text{.}\) Therefore
    \begin{align*} J_{f\circ G}(1,0)\amp=J_f(3,4)J_G(1,0)\\ \amp=\begin{bmatrix}10\amp2\end{bmatrix}\begin{bmatrix}3\amp2\\4\amp-1\end{bmatrix}\\ \amp=\begin{bmatrix}38\amp18\end{bmatrix}. \end{align*}
    Evaluating \(J_f\) at \((1,0)\) instead would use the wrong input to the outer function.
    🔗
    🔗
  3. The symbolic difference simplifies to the zero row for all \(u,v\text{,}\) verifying that the direct derivative and the chain-rule product agree for these polynomial functions. The row is the transpose of the gradient:
    \begin{equation*} \nabla(f\circ G)(u,v) =\begin{bmatrix}38u+18v\\18u+34v\end{bmatrix}. \end{equation*}
    Transposing \(J_{f\circ G}=J_f(G)J_G\) gives the equivalent column formula \(\nabla(f\circ G)=J_G^T(\nabla f\circ G)\text{.}\)
