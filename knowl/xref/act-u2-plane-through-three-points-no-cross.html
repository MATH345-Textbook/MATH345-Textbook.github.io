Activity 2.2.65. A plane through three points without cross products (U2-LO1, U2-LO2).

Use Gaussian elimination and basic solutions to find an equation for the plane containing
\begin{equation*} P(1,1,-2),\qquad Q(0,2,1),\qquad R(-1,-1,0), \end{equation*}
(without using the cross-product, if you happen to know what that is).
🔗
Solution.
First find two displacement vectors in the plane:
\begin{equation*} \mathbf{u}=\overrightarrow{PQ}=\begin{bmatrix}-1\\1\\3\end{bmatrix}, \qquad \mathbf{v}=\overrightarrow{PR}=\begin{bmatrix}-2\\-2\\2\end{bmatrix}. \end{equation*}
Let \(\mathbf{n}=\begin{bmatrix}a\\b\\c\end{bmatrix}\) be a nonzero normal vector. Then \(\mathbf{n}\) must be perpendicular to both displacement vectors:
\begin{equation*} -a+b+3c=0,\qquad -2a-2b+2c=0. \end{equation*}

Write this homogeneous system as an augmented matrix:
\begin{equation*} \left[\begin{array}{ccc|c} -1 \amp 1 \amp 3 \amp 0 \\ -2 \amp -2 \amp 2 \amp 0 \end{array}\right]. \end{equation*}
Apply Gaussian elimination, then clear the entry above the second pivot to obtain RREF:

\begin{equation*} R_1\to -R_1 \end{equation*}

\begin{equation*} \left[\begin{array}{ccc|c} 1 \amp -1 \amp -3 \amp 0 \\ -2 \amp -2 \amp 2 \amp 0 \end{array}\right] \end{equation*}
🔗
\begin{equation*} R_2\to R_2+2R_1 \end{equation*}
🔗
\begin{equation*} \left[\begin{array}{ccc|c} 1 \amp -1 \amp -3 \amp 0 \\ 0 \amp -4 \amp -4 \amp 0 \end{array}\right] \end{equation*}
🔗
\begin{equation*} R_2\to -\tfrac14 R_2 \end{equation*}
🔗
\begin{equation*} \left[\begin{array}{ccc|c} 1 \amp -1 \amp -3 \amp 0 \\ 0 \amp 1 \amp 1 \amp 0 \end{array}\right] \end{equation*}
🔗
\begin{equation*} R_1\to R_1+R_2 \end{equation*}
🔗
\begin{equation*} \left[\begin{array}{ccc|c} 1 \amp 0 \amp -2 \amp 0 \\ 0 \amp 1 \amp 1 \amp 0 \end{array}\right] \end{equation*}
🔗
The leading variables are \(a\) and \(b\text{,}\) and \(c\) is free. The reduced equations are
\begin{equation*} a-2c=0,\qquad b+c=0. \end{equation*}
Thus the general solution is
\begin{equation*} \begin{bmatrix}a\\b\\c\end{bmatrix} =\begin{bmatrix}2t\\-t\\t\end{bmatrix} =t\begin{bmatrix}2\\-1\\1\end{bmatrix},\qquad t\in\mathbb R. \end{equation*}
Following Definition 2.2.63, set the single free variable \(c=1\) to obtain the basic solution
\begin{equation*} \mathbf{n}=\begin{bmatrix}2\\-1\\1\end{bmatrix}. \end{equation*}
This nonzero vector is perpendicular to both displacement vectors, so it is a normal vector to the plane.
🔗
Using the point \(P(1,1,-2)\text{,}\) the plane equation is
\begin{equation*} 2(x-1)-(y-1)+(z+2)=0, \end{equation*}
or
\begin{equation*} 2x-y+z=-1. \end{equation*}
