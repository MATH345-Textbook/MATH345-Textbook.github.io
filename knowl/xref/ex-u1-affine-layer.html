Example 1.3.39. An affine layer.

An affine layer in a neural network takes the form
\begin{equation*} \mathbf{x}\mapsto W\mathbf{x}+\mathbf{b}. \end{equation*}
The symbol \(\mapsto\) means “maps to”: the input vector \(\mathbf{x}\) is sent to the output vector \(W\mathbf{x}+\mathbf{b}\text{.}\)
🔗
If the layer has \(n\) inputs and \(m\) neurons, then \(W\in\mathbb{R}^{m\times n}\) and \(\mathbf{b}\in\mathbb{R}^m\text{.}\) Writing \(\mathbf{z}=W\mathbf{x}+\mathbf{b}\text{,}\) the coordinate for neuron \(i\) is
\begin{equation*} z_i=\sum_{j=1}^{n}W_{ij}x_j+b_i,\qquad i=1,\ldots,m. \end{equation*}
This is the neuron’s weighted sum of the inputs plus its bias. Row \(i\) of \(W\) contains that neuron’s weights. The vector \(\mathbf{z}\) collects these quantities for all neurons in the layer.
🔗
The matrix \(W\) mixes the input coordinates, and the vector \(\mathbf{b}\) shifts the result. This map is affine.
