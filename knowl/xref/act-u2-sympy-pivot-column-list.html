Activity 2.4.41. Selecting original pivot columns in SymPy (U2-LO3, U2-LO4).

The pivot-column rule translates directly into code. The assignment R, pivots = A.rref() stores the reduced matrix and its zero-based pivot indices separately. Rows and columns are indexed starting at zero: A[i, j] selects one entry, so A[0, 2] is the entry in the first row and third column.
🔗
A colon means “take all entries in this direction”: A[:, j] selects every row of column j, while A[j, :] selects every column of row j.
🔗
import sympy as sp

A = sp.Matrix([
    [2, 4, 0],
    [1, 2, 1],
    [3, 6, 2],
])
R, pivots = A.rref()
R, pivots
Output:
🔗
(Matrix([
[1, 2, 0],
[0, 0, 1],
[0, 0, 0]]), (0, 2))
A list comprehension builds a list by evaluating an expression for each item in a sequence. Read [A[:, j] for j in pivots] as “for each pivot index j, take column j of A and put it in the list.”
🔗
columns = [A[:, j] for j in pivots]
columns
This is equivalent to the following loop; append adds one item to the end of a list.
🔗
columns = []
for j in pivots:
    columns.append(A[:, j])

Solution.
  1. The entry A[0, 2] is \(0\text{.}\) The indices (0, 2) select mathematical columns 1 and 3. The result is a list of two \(3\times1\) column matrices:
    🔗
    [Matrix([
[2],
[1],
[3]]), Matrix([
[0],
[1],
[2]])]
    🔗
  2. They are the original pivot columns, so the preceding theorem says they form a basis for \(\col(A)\text{.}\) The middle column is twice the first. Columns of R have been changed by row operations; here every vector in their span has third coordinate zero, whereas the selected original columns do not.
    🔗
    🔗
  3. The row expression selects rows 1 and 3 as \(1\times3\) matrices. Adding one to the pivot indices requests indices 1 and 3, but a three-column matrix has only indices 0, 1, 2. The latter request raises an IndexError. Add one only when translating an index into mathematical column numbering, not when indexing the matrix in Python.
