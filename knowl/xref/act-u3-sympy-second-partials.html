Activity 3.3.27. Reading repeated and mixed derivatives in SymPy (U3-LO3).
Return to the polynomial in Activity 3.3.5. The command sp.diff(f, x, 2) differentiates twice with respect to x. The command sp.diff(f, x, y) differentiates first with respect to x, then with respect to y; equivalently, it computes sp.diff(sp.diff(f, x), y).
🔗
import sympy as sp

x, y = sp.symbols("x y")
f = 3*x**2*y + 2*x - 3*y
dxx = sp.diff(f, x, 2)
d_x_then_y = sp.diff(f, x, y)
d_y_then_x = sp.diff(f, y, x)
dyy = sp.diff(f, y, 2)

print((dxx, d_x_then_y, d_y_then_x, dyy))
Output:
🔗
(6*y, 6*x, 6*x, 0)
  1. Match each output to \(f_{xx}\text{,}\) \(f_{xy}\text{,}\) \(f_{yx}\text{,}\) or \(f_{yy}\text{,}\) using this section’s differentiation-order convention.
    🔗
    🔗
  2. Starting from \(f_x=6xy+2\) and \(f_y=3x^2-3\text{,}\) verify the four outputs by hand.
    🔗
    🔗
  3. Why does Theorem 3.3.23 apply to this function? Does the matching output establish equality of mixed partial derivatives for every function?
    🔗
    🔗
Solution.
In order, the outputs are \(f_{xx}=6y\text{,}\) \(f_{xy}=6x\text{,}\) \(f_{yx}=6x\text{,}\) and \(f_{yy}=0\text{.}\) The leftmost subscript indicates the first differentiation: d_x_then_y represents \(f_{xy}=(f_x)_y\text{,}\) and d_y_then_x represents \(f_{yx}=(f_y)_x\text{.}\) Differentiating \(6xy+2\) in \(x\) and \(y\) gives \(6y\) and \(6x\text{;}\) differentiating \(3x^2-3\) in \(x\) and \(y\) gives \(6x\) and \(0\text{.}\)
🔗
This polynomial has continuous second partial derivatives everywhere, so Clairaut’s theorem guarantees the equality. The output checks this particular function; it does not remove the theorem’s hypotheses for other functions.
