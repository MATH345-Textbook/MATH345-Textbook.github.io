Algorithm 4.2.9. Gram-Schmidt algorithm.

Input: A matrix
\begin{equation*} A= \begin{bmatrix} \mathbf{a}_1 \amp \mathbf{a}_2 \amp \cdots \amp \mathbf{a}_n \end{bmatrix} \end{equation*}
with linearly independent columns.
🔗
For \(j=1,\ldots,n\text{:}\)
🔗
  1. Current column. Start with \(\mathbf{a}_j\text{.}\)
    🔗
    🔗
  2. Project. For each \(i \lt j\text{,}\) compute
    \begin{equation*} r_{ij}=\mathbf{q}_i^T\mathbf{a}_j. \end{equation*}
    Then assemble
    \begin{equation*} \mathbf{p}_j=\sum_{i \lt j}r_{ij}\mathbf{q}_i. \end{equation*}
    For the first column, \(\mathbf{p}_1=\mathbf{0}\text{.}\)
    🔗
    🔗
  3. Subtract.
    \begin{equation*} \mathbf{v}_j=\mathbf{a}_j-\mathbf{p}_j. \end{equation*}
    🔗
    🔗
  4. Measure.
    \begin{equation*} r_{jj}=\|\mathbf{v}_j\|. \end{equation*}
    🔗
    🔗
  5. Normalize.
    \begin{equation*} \mathbf{q}_j=\frac{\mathbf{v}_j}{r_{jj}}. \end{equation*}
    🔗
    🔗
Output: The vectors \(\mathbf{q}_1,\ldots,\mathbf{q}_n\) are orthonormal, and
\begin{equation*} \spans\{\mathbf{q}_1,\ldots,\mathbf{q}_j\} = \spans\{\mathbf{a}_1,\ldots,\mathbf{a}_j\} \end{equation*}
at every stage.
