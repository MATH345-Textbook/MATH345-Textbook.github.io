Solution.
The vector xhat is a least-squares coefficient vector. The vector r is the residual
\begin{equation*} \mathbf r=\mathbf b-A\widehat{\mathbf x}. \end{equation*}
The expression A.T @ r checks numerically whether
\begin{equation*} A^T\mathbf r=\mathbf0. \end{equation*}
Unit 4 interprets this condition as residual orthogonality. In the current section,
\begin{equation*} \nabla L(\widehat{\mathbf x}) = 2A^T(A\widehat{\mathbf x}-\mathbf b) = -2A^T\mathbf r, \end{equation*}
so the same calculation also checks whether the gradient is zero.
