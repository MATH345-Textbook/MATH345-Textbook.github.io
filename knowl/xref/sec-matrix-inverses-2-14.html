Theorem 2.5.11.

Let \(T:\R^n\to\R^n\) denote the matrix transformation induced by an \(n \times n\) matrix \(A\text{.}\) Then:
🔗
  1. \(A\) is invertible if and only if \(T\) has an inverse.
    🔗
  2. In this case, \(T\) has exactly one inverse (which we denote as \(T^{-1}\)), and \(T^{-1} : \R^n\to\R^n\) is the transformation induced by the matrix \(A^{-1}\text{.}\)
    🔗
In other words, \((T_A)^{-1} = T_{A^{-1}}\text{.}\)
🔗
\(T\) and \(T^{-1}\) ‘reverse’ or ‘undo’ the action of each other.
