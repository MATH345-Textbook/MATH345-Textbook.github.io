Activity 2.4.56. Using a SymPy null-space vector (U2-LO3, U2-LO4, U2-LO6).

The command A.nullspace() returns a Python list of basis vectors, each stored as a SymPy column matrix. With a nonempty list called basis, basis[0] selects its first vector, since list indices start at zero. The number of vectors is len(basis), which gives the nullity. If the null space is \(\{\mathbf{0}\}\text{,}\) the returned list is empty and has no first item.
🔗
import sympy as sp

A = sp.Matrix([
    [1, 0, 2],
    [0, 1, -1],
    [2, 1, 3],
])
basis = A.nullspace()
basis
Output:
🔗
[Matrix([
[-2],
[ 1],
[ 1]])]
With two numbers, * is ordinary multiplication; with a number and a matrix, it scales every entry. With two SymPy matrices, * means matrix multiplication, so A * z is the matrix-vector product when z is a column matrix. A flat list passed to sp.Matrix, such as sp.Matrix([-2, 1, 1]), creates that column matrix. This differs from NumPy arrays, where A @ z is the matrix-vector product and * acts entry by entry.
🔗
The command sp.ones(3, 1) creates a \(3\times1\) column of ones. The attribute z.T is the transpose, a \(1\times3\) row, and z.shape reports the pair (rows, columns).

Solution.
  1. The list contains one basis vector, so len(basis) is 1 and the nullity is \(1\text{.}\) The vector has three rows and one column, so z.shape is (3, 1). The product is
    🔗
    Matrix([
[0],
[0],
[0]])
    🔗
  2. basis is a list containing a matrix; it is not itself the column matrix. A * basis raises a TypeError. Selecting basis[0] supplies the vector needed for the product.
    🔗
    🔗
  3. The two products are
    🔗
    \begin{equation*} A\begin{bmatrix}1\\1\\1\end{bmatrix}=\begin{bmatrix}3\\0\\6\end{bmatrix},\qquad \mathbf{z}^{T}A=\begin{bmatrix}0\amp2\amp-2\end{bmatrix}. \end{equation*}
    The first is a nonzero column; the second is a nonzero row. Transposing a null-space vector changes both the order and the meaning of the multiplication.
    🔗
    🔗
  4. Since \(A\mathbf{z}=\mathbf{0}\text{,}\) linearity gives \(A(\mathbf{x}+t\mathbf{z})=A\mathbf{x}\) for every scalar \(t\text{.}\) Changing an input by this null-space direction leaves its output unchanged.
