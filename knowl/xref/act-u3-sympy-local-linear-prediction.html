Activity 3.4.22. Reading a local linear prediction in SymPy (U3-LO5).

Use SymPy to revisit the nonlinear shear \(F(x,y)=(x+y^2,y)\) from Activity 3.4.18. We evaluate its Jacobian at \(\mathbf{a}=(0,1/2)\text{,}\) then use that matrix to predict the output after a small input change. The command sp.Rational(p, q) represents the fraction \(p/q\) exactly. As in Activity 2.4.56, * between SymPy matrices means matrix multiplication.
🔗
import sympy as sp

x, y = sp.symbols("x y")
F = sp.Matrix([x + y**2, y])
a = sp.Matrix([0, sp.Rational(1, 2)])
h = sp.Matrix([sp.Rational(1, 10), -sp.Rational(1, 10)])

J = F.jacobian([x, y])
Ja = J.subs({x: a[0], y: a[1]})
Fa = F.subs({x: a[0], y: a[1]})
prediction = Fa + Ja*h
actual = F.subs({x: a[0] + h[0], y: a[1] + h[1]})

print(Ja)
print(Ja*h)
print(prediction)
print(actual)
print(actual - prediction)

Solution.
  1. The shapes are (2, 2), (2, 1), and (2, 1). The matrix \(J_F(\mathbf{a})=\begin{bmatrix}1\amp1\\0\amp1\end{bmatrix}\) is the horizontal shear from Unit 1, now acting on the input change \(\mathbf{h}\text{.}\) Its product with \(\mathbf{h}\) predicts \(F(\mathbf{a}+\mathbf{h})-F(\mathbf{a})\text{.}\) To predict the output itself, add the starting output \(F(\mathbf{a})\text{.}\)
    🔗
    🔗
  2. The affine prediction is
    \begin{equation*} \begin{bmatrix}1/4\\1/2\end{bmatrix} +\begin{bmatrix}1\amp1\\0\amp1\end{bmatrix} \begin{bmatrix}1/10\\-1/10\end{bmatrix} =\begin{bmatrix}1/4\\2/5\end{bmatrix}. \end{equation*}
    The actual output is \(F(1/10,2/5)=(13/50,2/5)\text{.}\) The second coordinate is exact; the first is underestimated by \(1/100\text{.}\)
    🔗
    🔗
  3. The error for this map is \((h_2^2,0)\text{.}\) Replacing \(\mathbf{h}\) by \(\mathbf{h}/2\) gives the error \((1/400,0)\text{,}\) one quarter of the original error. This agrees with the closer fit in the smaller-square visualization.
