Activity 2.4.46. Finding the rank of a matrix (U2-LO3).

Find the rank of the matrix
🔗
\begin{equation*} C = \left[\begin{array}{cccc} 1 \amp 1 \amp 2 \amp 7 \\ 0 \amp 1 \amp 0 \amp 3 \\ 2 \amp 1 \amp 4 \amp 11 \end{array}\right] \end{equation*}
Solution.
We convert the matrix to row echelon form using Algorithm 2.2.40. Subtract 2 times Row 1 from Row 3:
🔗
\begin{equation*} \left[\begin{array}{cccc} 1 \amp 1 \amp 2 \amp 7 \\ 0 \amp 1 \amp 0 \amp 3 \\ 0 \amp -1 \amp 0 \amp -3 \end{array}\right] \end{equation*}
Add Row 2 to Row 3:
🔗
\begin{equation*} \left[\begin{array}{cccc} 1 \amp 1 \amp 2 \amp 7 \\ 0 \amp 1 \amp 0 \amp 3 \\ 0 \amp 0 \amp 0 \amp 0 \end{array}\right] \end{equation*}
The matrix is now in REF with 2 leading ones, and so the rank of \(C\) is \(2\text{.}\)
