Fact 2.3.29. Spanning and solvability.

Let \(A\) be an \(m\times n\) matrix with columns \(\mathbf{c}_1,\ldots,\mathbf{c}_n\text{.}\) Then \(A\mathbf{x}=\mathbf{b}\) has a solution for every \(\mathbf{b}\in\R^m\) if and only if \(\spans\{\mathbf{c}_1,\ldots,\mathbf{c}_n\}=\R^m\text{.}\)
🔗
🔗

Why is this true?.

As noted in the earlier discussion of matrix columns,
\begin{equation*} A\mathbf{x}=x_1\mathbf{c}_1+\cdots+x_n\mathbf{c}_n. \end{equation*}
Thus \(A\mathbf{x}=\mathbf{b}\) has a solution exactly when \(\mathbf{b}\) is a linear combination of the columns of \(A\text{.}\) By Definition 2.3.22, this holds for every \(\mathbf{b}\in\R^m\) exactly when the columns span \(\R^m\text{.}\)
