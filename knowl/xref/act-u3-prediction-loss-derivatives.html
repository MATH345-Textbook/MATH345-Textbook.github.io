Activity 3.3.37. How model weights change the loss (U3-LO3).
For the fixed data in Activity 3.1.9,
\begin{equation*} \mathcal L(w_1,w_2)=(w_1-1)^2+(w_2-2)^2+(w_1+w_2-2)^2. \end{equation*}
We will continue to use the starting weights \(\mathbf{w}_0=(1,1)\text{.}\)
🔗
  1. Find both first partial derivatives and assemble \(\nabla\mathcal L\text{.}\) Evaluate it at \(\mathbf{w}_0\text{.}\) Interpret each component while holding the other weight fixed.
    🔗
    🔗
  2. Compute the Hessian \(H_{\mathcal L}\text{.}\) Verify by matrix multiplication that it equals \(2X^TX\) for the data matrix \(X\text{.}\)
    🔗
    🔗
  3. The first partial derivative in \(w_1\) vanishes at \(\mathbf{w}_0\text{.}\) Does this mean the loss is unchanged whenever we change \(w_1\text{?}\) Check by expanding \(\mathcal L(1+t,1)\text{.}\)
    🔗
    🔗
You can check your derivative formulas using the SymPy commands in Activity 3.3.36.
🔗
Solution.
  1. Differentiating one weight at a time gives
    \begin{align*} \mathcal L_{w_1}(\mathbf{w})\amp=2(w_1-1)+2(w_1+w_2-2)\\ \amp=4w_1+2w_2-6,\\ \mathcal L_{w_2}(\mathbf{w})\amp=2(w_2-2)+2(w_1+w_2-2)\\ \amp=2w_1+4w_2-8. \end{align*}
    Thus
    \begin{align*} \nabla\mathcal L(\mathbf{w})\amp=\begin{bmatrix}4w_1+2w_2-6\\2w_1+4w_2-8\end{bmatrix},\\ \nabla\mathcal L(1,1)\amp=\begin{bmatrix}0\\-2\end{bmatrix}. \end{align*}
    At these weights, the instantaneous rate of change in \(w_1\) is zero when \(w_2=1\) is fixed. Increasing \(w_2\) slightly while keeping \(w_1=1\) decreases the loss at a rate of \(2\) units of loss per unit increase in \(w_2\text{.}\)
    🔗
    🔗
  2. Differentiate each first partial derivative with respect to each weight, holding the other weight fixed:
    \begin{align*} \mathcal L_{w_1w_1}(\mathbf{w})\amp=\frac{\partial}{\partial w_1}(4w_1+2w_2-6)=4,\\ \mathcal L_{w_1w_2}(\mathbf{w})\amp=\frac{\partial}{\partial w_2}(4w_1+2w_2-6)=2,\\ \mathcal L_{w_2w_1}(\mathbf{w})\amp=\frac{\partial}{\partial w_1}(2w_1+4w_2-8)=2,\\ \mathcal L_{w_2w_2}(\mathbf{w})\amp=\frac{\partial}{\partial w_2}(2w_1+4w_2-8)=4. \end{align*}
    These four second partial derivatives are constant, so the Hessian is
    \begin{equation*} H_{\mathcal L}(\mathbf{w})=\begin{bmatrix}4\amp2\\2\amp4\end{bmatrix} =2\begin{bmatrix}1\amp0\amp1\\0\amp1\amp1\end{bmatrix} \begin{bmatrix}1\amp0\\0\amp1\\1\amp1\end{bmatrix} =2X^TX. \end{equation*}
    Its entries describe how the first partial derivatives change as the weights change.
    🔗
    🔗
  3. Direct substitution gives \(\mathcal L(1+t,1)=t^2+(-1)^2+t^2=1+2t^2\text{.}\) The zero partial derivative describes the rate at \(t=0\text{;}\) the quadratic term changes the loss for every nonzero \(t\text{.}\) This is not an exactly forgotten direction of the prediction map from Unit 2.
    🔗
    🔗
