Activity 3.1.19. Equal-error curves in parameter space (U3-LO1).

Return to the loss from Activity 3.1.9:
\begin{equation*} \mathcal L(w_1,w_2)=(w_1-1)^2+(w_2-2)^2+(w_1+w_2-2)^2. \end{equation*}
🔗
  1. Describe the coordinates of a point on the graph of \(\mathcal L\text{.}\) Which coordinates represent model weights, and which represents prediction error?
    🔗
    🔗
  2. Write the equation of the level curve \(\mathcal L=1\text{.}\) Locate \((1,1)\) and \((0,2)\) on this curve, and give the corresponding points on the graph. What would moving along this level curve preserve?
    🔗
    🔗
  3. Can a level curve have a negative loss value? Is the level set \(\mathcal L=0\) nonempty for these data?
    🔗
    🔗
Solution.
  1. The graph is the surface of points \((w_1,w_2,\mathcal L(w_1,w_2))\) in \(\R^3\text{.}\) Its first two coordinates are adjustable weights; its height is the total squared prediction error. The input domain is the entire parameter plane \(\R^2\text{.}\)
    🔗
    🔗
  2. The level curve is
    \begin{equation*} (w_1-1)^2+(w_2-2)^2+(w_1+w_2-2)^2=1. \end{equation*}
    Both \((1,1)\) and \((0,2)\) satisfy this equation. Their graph points are \((1,1,1)\) and \((0,2,1)\text{.}\) A horizontal slice of the graph at height \(1\) gives this level curve when viewed in the parameter plane. The two choices have equal total squared error, although their predictions differ as computed in Activity 3.1.9.
    🔗
    🔗
  3. Every term is a square, so a negative level set is empty. The zero level set is also empty for these data, because \(X\mathbf{w}=\mathbf{y}\) is inconsistent. A nonnegative formula does not guarantee that the value zero is attained.
