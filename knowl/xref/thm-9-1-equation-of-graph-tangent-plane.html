Theorem 3.4.11. Equation of the Tangent Plane.
Suppose \(S\) is the graph of a function \(f(x,y)\) which is differentiable at a point \((x_0,y_0)\text{.}\) Then the tangent plane to \(S\) exists, is unique, and is described by the equation
\begin{equation*} z = f(x_0,y_0) + f_x(x_0,y_0) ( x - x_0 ) + f_y(x_0,y_0) (y - y_0)\text{.} \end{equation*}
Note that this plane is the graph of the linear approximation \(L\) to \(f\) at \((x_0,y_0)\text{.}\)
🔗
🔗
Why is this true?.
We verify that the plane described by the equation above is the only possible tangent plane. Recall from Theorem 3.3.9 that the intersection of \(S\) with the plane \(y=y_0\) is the curve \(z=f(x,y_0)\text{,}\) whose slope at \(x=x_0\) is \(f_x(x_0,y_0)\text{.}\) Its tangent line therefore has equations
\begin{equation*} y=y_0,\qquad z=f(x_0,y_0)+f_x(x_0,y_0)(x-x_0). \end{equation*}
🔗
Set \(t=x-x_0\text{,}\) so that \(x=x_0+t\text{.}\) The line can then be parameterized as
\begin{equation*} \mathbf{r}_1(t)=\begin{bmatrix}x_0\\y_0\\f(x_0,y_0)\end{bmatrix}+t\begin{bmatrix}1\\0\\f_x(x_0,y_0)\end{bmatrix}. \end{equation*}
The vector multiplying \(t\) is a direction vector: a change of \(t\) in \(x\) leaves \(y\) fixed and changes \(z\) by \(f_x(x_0,y_0)t\text{.}\) This gives the direction vector \((1,0,f_x(x_0,y_0))\text{.}\)
🔗
Similarly, the intersection with \(x=x_0\) is the curve \(z=f(x_0,y)\text{,}\) whose tangent line has equations
\begin{equation*} x=x_0,\qquad z=f(x_0,y_0)+f_y(x_0,y_0)(y-y_0). \end{equation*}
Taking \(s=y-y_0\) gives the parameterization
\begin{equation*} \mathbf{r}_2(s)=\begin{bmatrix}x_0\\y_0\\f(x_0,y_0)\end{bmatrix}+s\begin{bmatrix}0\\1\\f_y(x_0,y_0)\end{bmatrix}. \end{equation*}
Here \(x\) stays fixed while \(y\) changes by \(s\) and \(z\) changes by \(f_y(x_0,y_0)s\text{,}\) so the direction vector is \((0,1,f_y(x_0,y_0))\text{.}\)
🔗
Following the method of Activity 3.4.8, write a normal vector as \(\mathbf{n}=(a,b,c)\) and require it to be perpendicular to both direction vectors. Taking the two dot products gives the homogeneous system
\begin{align*} a+f_x(x_0,y_0)c \amp=0,\\ b+f_y(x_0,y_0)c \amp=0. \end{align*}
With the variables in the order \(a,b,c\text{,}\) its augmented matrix is
\begin{equation*} \left[\begin{array}{ccc|c} 1 \amp 0 \amp f_x(x_0,y_0) \amp 0\\ 0 \amp 1 \amp f_y(x_0,y_0) \amp 0 \end{array}\right]. \end{equation*}
🔗
This matrix is already in row echelon form (in fact, reduced row echelon form), so no row operations are needed. The first two columns are pivot columns: \(a\) and \(b\) are basic variables, while \(c\) is free. Reading the equations gives
\begin{equation*} a=-f_x(x_0,y_0)c,\qquad b=-f_y(x_0,y_0)c. \end{equation*}
Setting the free variable \(c=1\) gives the basic solution
\begin{equation*} \mathbf{n}=\begin{bmatrix}-f_x(x_0,y_0)\\-f_y(x_0,y_0)\\1\end{bmatrix}. \end{equation*}
This vector is nonzero and perpendicular to both tangent-line directions, so it is a normal vector to the plane containing the two lines.
🔗
Thus the tangent plane to \(S\) at \((x_0,y_0,f(x_0,y_0))\) must be described by the equation
\begin{equation*} (-f_x(x_0,y_0),- f_y(x_0,y_0),1) \cdot ( x - x_0, y - y_0, z - f(x_0,y_0) ) = 0\text{,} \end{equation*}
an equation we may rearrange to read
\begin{equation*} z = f(x_0,y_0) + f_x(x_0,y_0) ( x - x_0 ) + f_y(x_0,y_0) ( y - y_0 )\text{.} \end{equation*}
