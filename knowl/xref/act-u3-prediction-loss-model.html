Activity 3.1.9. From predictions to a scalar error function (U3-LO1, U2-LO1).

As in Activity 2.1.7, the input to a prediction map is a vector of model coefficients. Consider three observations with two numerical features each:
\begin{equation*} X=\begin{bmatrix}1\amp0\\0\amp1\\1\amp1\end{bmatrix}, \qquad \mathbf{y}=\begin{bmatrix}1\\2\\2\end{bmatrix}. \end{equation*}
Each row of \(X\) gives one observation’s features, and the corresponding entry of \(\mathbf{y}\) is its observed response. Both \(X\) and \(\mathbf{y}\) stay fixed. The two adjustable weights are \(\mathbf{w}=(w_1,w_2)\text{.}\)
🔗
The prediction vector and the error vector, also called the residual, are
\begin{equation*} P(\mathbf{w})=X\mathbf{w} =\begin{bmatrix}w_1\\w_2\\w_1+w_2\end{bmatrix}, \qquad R(\mathbf{w})=X\mathbf{w}-\mathbf{y}. \end{equation*}
Using the vector length from Definition 1.1.4, we summarize these three errors by the squared-error loss
\begin{equation*} \mathcal L(\mathbf{w})=\|X\mathbf{w}-\mathbf{y}\|^2 =(w_1-1)^2+(w_2-2)^2+(w_1+w_2-2)^2. \end{equation*}
A smaller loss means a better fit to these observations.
🔗
  1. Give the domains and co-domains of \(P\text{,}\) \(R\text{,}\) and \(\mathcal L\text{.}\) Which are vector-valued, and which is scalar-valued? Which map is linear, and which is affine?
    🔗
    🔗
  2. Compute the predictions, residuals, and losses at \(\mathbf{w}_0=(1,1)\) and \(\mathbf{b}=(0,2)\text{.}\) Does equal loss imply equal predictions?
    🔗
    🔗
  3. Could any choice of weights give loss zero? Translate this question into a linear system and use Unit 2’s row-reduction method.
    🔗
    🔗
Solution.
  1. The maps \(P,R:\R^2\to\R^3\) are vector-valued, while \(\mathcal L:\R^2\to\R\) is scalar-valued. All are defined for every pair of real weights. The map \(P\) is linear, and \(R\) is affine because it subtracts the fixed vector \(\mathbf{y}\text{.}\) The loss is a nonlinear quadratic function; in particular, \(\mathcal L(\mathbf{0})=9\text{,}\) so it is not linear.
    🔗
    🔗
  2. The two computations give
    \begin{align*} P(1,1)\amp=\begin{bmatrix}1\\1\\2\end{bmatrix}, \quad R(1,1)=\begin{bmatrix}0\\-1\\0\end{bmatrix},\\ \mathcal L(1,1)\amp=1, \end{align*}
    and
    \begin{align*} P(0,2)\amp=\begin{bmatrix}0\\2\\2\end{bmatrix}, \quad R(0,2)=\begin{bmatrix}-1\\0\\0\end{bmatrix},\\ \mathcal L(0,2)\amp=1. \end{align*}
    The scalar loss records the total squared error, so different prediction and residual vectors can give the same loss.
    🔗
    🔗
  3. A sum of squares is zero precisely when every error is zero. Thus we would need \(X\mathbf{w}=\mathbf{y}\text{.}\) Row reduction gives
    \begin{align*} \left[\begin{array}{cc|c}1\amp0\amp1\\0\amp1\amp2\\1\amp1\amp2\end{array}\right] \amp\xrightarrow{R_3\to R_3-R_1} \left[\begin{array}{cc|c}1\amp0\amp1\\0\amp1\amp2\\0\amp1\amp1\end{array}\right]\\ \amp\xrightarrow{R_3\to R_3-R_2} \left[\begin{array}{cc|c}1\amp0\amp1\\0\amp1\amp2\\0\amp0\amp-1\end{array}\right]. \end{align*}
    The last row says \(0=-1\text{,}\) so no exact fit is possible. This motivates improving the fit by decreasing the loss even when all three predictions cannot be correct at once.
