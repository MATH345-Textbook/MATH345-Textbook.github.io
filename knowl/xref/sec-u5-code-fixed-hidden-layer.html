Solution.
The columns of A are the fixed feature vectors
\begin{equation*} \mathbf 1,\qquad \bigl[\tanh(t_i)\bigr]_{i=1}^m,\qquad \bigl[\tanh(t_i-1)\bigr]_{i=1}^m,\qquad \bigl[\tanh(t_i+1)\bigr]_{i=1}^m, \end{equation*}
where each bracketed vector is evaluated entrywise at the data inputs. The trained vector is \(\mathbf c\text{.}\) The vector yhat contains the fitted values
\begin{equation*} A\mathbf c. \end{equation*}
🔗
The variable loss stores
\begin{equation*} \|A\mathbf c-\mathbf y\|^2. \end{equation*}
🔗
The command np.linalg.lstsq applies because \(A\) is fixed and the prediction vector is linear in \(\mathbf c\text{.}\) The shifts \(0,1,-1\) inside the feature functions are not being fitted.
