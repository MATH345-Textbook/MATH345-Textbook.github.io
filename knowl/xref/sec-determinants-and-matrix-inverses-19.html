Fact 2.5.33.

For an \(n\times n\) matrix, cofactor expansion along any row or any column gives the same determinant:
🔗
\begin{equation*} \det(A)=\sum_{j=1}^{n} a_{ij}\operatorname{cof}(A)_{ij} \end{equation*}
for any fixed row \(i\text{,}\) and
🔗
\begin{equation*} \det(A)=\sum_{i=1}^{n} a_{ij}\operatorname{cof}(A)_{ij} \end{equation*}
for any fixed column \(j\text{.}\)
