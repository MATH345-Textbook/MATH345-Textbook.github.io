Activity 3.4.25. Interpreting a Jacobian’s null space in SymPy (U3-LO5, U2-LO3).

In Activity 2.4.56, a null-space vector described an input change that a linear map forgets. Apply the same tools to the local linear map of \(F(x,y)=(x+y,x^2+y^2)\) at \(\mathbf{a}=(1,1)\text{.}\) Recall that .rref() returns the reduced matrix and zero-based pivot-column indices, while .nullspace() returns a list of basis column matrices.
🔗
import sympy as sp

x, y = sp.symbols("x y")
F = sp.Matrix([x + y, x**2 + y**2])
J = F.jacobian([x, y])
Ja = J.subs({x: 1, y: 1})

R, pivots = Ja.rref()
basis = Ja.nullspace()
v = basis[0]

print(Ja)
print(R, pivots)
print(len(basis), v)
print(Ja*v)

Solution.
  1. The row operation \(R_2\to R_2-2R_1\) gives
    \begin{equation*} \begin{bmatrix}1\amp1\\2\amp2\end{bmatrix} \longrightarrow \begin{bmatrix}1\amp1\\0\amp0\end{bmatrix}. \end{equation*}
    There is one pivot and one free variable, so the rank and nullity are both \(1\text{.}\) The pivot index 0 selects the first column of the original matrix, \((1,2)\text{.}\) Thus the possible first-order output changes form \(\operatorname{span}\{(1,2)\}\text{,}\) since \(J_F(\mathbf{a})\mathbf{h}=(h_1+h_2)(1,2)\text{.}\)
    🔗
    🔗
  2. Since \(J_F(\mathbf{a})\mathbf{v}=\mathbf{0}\text{,}\) the prediction is
    \begin{equation*} F(\mathbf{a}+t\mathbf{v}) \approx F(\mathbf{a})+tJ_F(\mathbf{a})\mathbf{v} =\begin{bmatrix}2\\2\end{bmatrix}. \end{equation*}
    Changing the two input coordinates by opposite amounts produces no first-order output change at this base point.
    🔗
    🔗
  3. Direct substitution gives
    \begin{align*} F(1-t,1+t)\amp=\begin{bmatrix}(1-t)+(1+t)\\(1-t)^2+(1+t)^2\end{bmatrix}\\ \amp=\begin{bmatrix}2\\2+2t^2\end{bmatrix}. \end{align*}
    The actual change is \((0,2t^2)\text{,}\) which equals \((0,1/50)\) when \(t=1/10\text{.}\) Unit 2’s identity \(A(\mathbf{x}+t\mathbf{v})=A\mathbf{x}\) holds exactly when \(A\mathbf{v}=\mathbf{0}\text{.}\) Here the null-space calculation describes the first-order behavior of \(F\) at \(\mathbf{a}\text{;}\) the quadratic term still changes the second output coordinate.
    🔗
    🔗
  4. At \((1,0)\text{,}\) the Jacobian is \(\begin{bmatrix}1\amp1\\2\amp0\end{bmatrix}\text{.}\) Row-reducing its homogeneous system gives
    \begin{align*} \amp \left[\begin{array}{cc|c}1\amp1\amp0\\2\amp0\amp0\end{array}\right] \xrightarrow{R_2\to R_2-2R_1} \left[\begin{array}{cc|c}1\amp1\amp0\\0\amp-2\amp0\end{array}\right]\\ \amp \quad \xrightarrow{R_2\to-\frac12R_2} \left[\begin{array}{cc|c}1\amp1\amp0\\0\amp1\amp0\end{array}\right]. \end{align*}
    Back-substitution gives \(v_2=0\) and then \(v_1=0\text{.}\) The command returns [], an empty basis list, and the rank is \(2\text{.}\) The rank and null space of a Jacobian can change with the base point.
