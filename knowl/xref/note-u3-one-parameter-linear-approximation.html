Note 3.4.16. Linear approximation in the one-parameter case.

For a differentiable one-parameter map \(\mathbf{r}:\R\to\R^m\text{,}\) the Jacobian has \(m\) rows and one column:
\begin{equation*} J_{\mathbf{r}}(a) =\begin{bmatrix}r_1'(a)\\\vdots\\r_m'(a)\end{bmatrix} =\mathbf{r}'(a). \end{equation*}
The input change \(t-a\) is a scalar, so the linear approximation becomes
\begin{equation*} L(t)=\mathbf{r}(a)+(t-a)\mathbf{r}'(a). \end{equation*}
When \(\mathbf{r}'(a)\ne\mathbf{0}\text{,}\) this parameterizes the tangent line to the curve at \(\mathbf{r}(a)\text{.}\) In the scalar-valued case, it reduces to the familiar formula \(L(t)=f(a)+f'(a)(t-a)\text{.}\)
