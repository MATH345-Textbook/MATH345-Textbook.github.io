Note 1.3.33. Linear functions are dot products.

By Theorem 1.3.30, every linear function is represented by a \(1\times n\) matrix. Writing this row matrix as \(\mathbf{c}^T\text{,}\) where \(\mathbf{c}\in\mathbb R^n\) is a fixed column vector, gives
\begin{align*} f(\mathbf{x}) \amp=\begin{bmatrix}c_1\amp\cdots\amp c_n\end{bmatrix}\begin{bmatrix}x_1\\\vdots\\x_n\end{bmatrix}\\ \amp=c_1x_1+\cdots+c_nx_n\\ \amp=\mathbf{c}^T\mathbf{x}=\mathbf{c}\cdot\mathbf{x}. \end{align*}
Conversely, every function of this form is linear by Theorem 1.3.29. Thus linear functions are exactly dot products with fixed vectors.
🔗
The vector \(\mathbf{c}\) is uniquely determined by the values of \(f\) on the standard basis vectors:
\begin{equation*} c_i=f(\mathbf{e}_i),\qquad i=1,\ldots,n. \end{equation*}
