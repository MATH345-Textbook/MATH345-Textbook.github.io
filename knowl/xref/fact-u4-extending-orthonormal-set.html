Fact 4.2.20. Expanding an orthonormal set.

Let \(\{\mathbf{q}_1,\ldots,\mathbf{q}_m\}\) be an orthonormal set in \(\R^n\text{,}\) and let \(\mathbf{x}\in\R^n\) lie outside its span. Define
\begin{equation*} \mathbf{v}=\mathbf{x}-(\mathbf{x}\cdot\mathbf{q}_1)\mathbf{q}_1-\cdots-(\mathbf{x}\cdot\mathbf{q}_m)\mathbf{q}_m. \end{equation*}
Then \(\mathbf{v}\neq\mathbf{0}\text{.}\) Normalize it by setting
\begin{equation*} \mathbf{q}_{m+1}=\frac{\mathbf{v}}{\|\mathbf{v}\|}. \end{equation*}
The enlarged set \(\{\mathbf{q}_1,\ldots,\mathbf{q}_m,\mathbf{q}_{m+1}\}\) is an orthonormal set, and the span is preserved:
\begin{equation*} \spans\{\mathbf{q}_1,\ldots,\mathbf{q}_m,\mathbf{q}_{m+1}\}=\spans\{\mathbf{q}_1,\ldots,\mathbf{q}_m,\mathbf{x}\}. \end{equation*}

Why is this true?.

If \(\mathbf{v}=\mathbf{0}\text{,}\) then \(\mathbf{x}=(\mathbf{x}\cdot\mathbf{q}_1)\mathbf{q}_1+\cdots+(\mathbf{x}\cdot\mathbf{q}_m)\mathbf{q}_m\) lies in the original span, contrary to the hypothesis. Thus \(\mathbf{v}\neq\mathbf{0}\) and we can normalize it. By Fact 4.2.4, \(\mathbf{v}\) is orthogonal to every \(\mathbf{q}_k\text{.}\) The vector \(\mathbf{q}_{m+1}\) has norm one and remains orthogonal to every \(\mathbf{q}_k\text{,}\) so the enlarged set is orthonormal.
🔗
The formula for \(\mathbf{q}_{m+1}\) expresses it as a linear combination of \(\mathbf{q}_1,\ldots,\mathbf{q}_m,\mathbf{x}\text{.}\) Conversely,
\begin{equation*} \mathbf{x}=(\mathbf{x}\cdot\mathbf{q}_1)\mathbf{q}_1+\cdots+(\mathbf{x}\cdot\mathbf{q}_m)\mathbf{q}_m+\|\mathbf{v}\|\mathbf{q}_{m+1}. \end{equation*}
Each set therefore spans the other, proving the equality of spans.
