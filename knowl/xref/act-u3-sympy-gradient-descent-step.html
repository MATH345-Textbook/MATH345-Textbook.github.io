Activity 3.6.30. From a symbolic gradient to a descent step (U3-LO9).

Use SymPy to check the first step of the preceding calculation for \(f(x,y)=x^2-3xy+3y^2+5y+2x\text{.}\) We construct a gradient as in Activity 3.3.36, evaluate it at the starting point, and apply the gradient-descent update. The learning rate sp.Rational(1, 10) represents \(0.1\) exactly.
🔗
import sympy as sp

x, y = sp.symbols("x y")
f = x**2 - 3*x*y + 3*y**2 + 5*y + 2*x
grad_f = sp.Matrix([sp.diff(f, x), sp.diff(f, y)])

p0 = sp.Matrix([0, 0])
g0 = grad_f.subs({x: p0[0], y: p0[1]})
alpha = sp.Rational(1, 10)
p1 = p0 - alpha*g0
f0 = f.subs({x: p0[0], y: p0[1]})
f1 = f.subs({x: p1[0], y: p1[1]})

print(grad_f)
print(g0)
print(p1)
print(f0, f1)
print((g0.T * (p1 - p0))[0], f1 - f0)
Output:
🔗
Matrix([[2*x - 3*y + 2], [-3*x + 6*y + 5]])
Matrix([[2], [5]])
Matrix([[-1/5], [-1/2]])
0 -241/100
-29/10 -241/100
In the last line, g0.T * (p1 - p0) is a \(1\times1\) matrix. The index [0] extracts its scalar entry, the local linear prediction for the change in \(f\text{.}\)

Solution.
  1. The matrix grad_f contains expressions for the two partial derivatives as functions of \(x,y\text{;}\) g0 is their value at \((0,0)\text{.}\) Each point and evaluated gradient is a \(2\times1\) column, so the scalar multiple alpha*g0 can be subtracted from p0.
    🔗
    🔗
  2. The update is
    \begin{equation*} \mathbf{p}_1 =\begin{bmatrix}0\\0\end{bmatrix} -\frac{1}{10}\begin{bmatrix}2\\5\end{bmatrix} =\begin{bmatrix}-1/5\\-1/2\end{bmatrix}. \end{equation*}
    The function value decreases from \(0\) to \(-241/100=-2.41\text{.}\) The local linear approximation predicts
    \begin{equation*} \nabla f(\mathbf{p}_0)^T(\mathbf{p}_1-\mathbf{p}_0) =-\frac{1}{10}(2^2+5^2) =-\frac{29}{10}. \end{equation*}
    The actual change is \(-241/100\text{.}\) Both are negative, but the actual decrease is smaller than predicted because the linear approximation omits nonlinear terms.
    🔗
    🔗
  3. Evaluating at the new point gives
    \begin{equation*} \nabla f(-1/5,-1/2) =\begin{bmatrix}31/10\\13/5\end{bmatrix}, \end{equation*}
    so \(\mathbf{p}_1\) is not a critical point. The symbolic expression grad_f can be reused without differentiating again. Its value must be recomputed at the new point; reusing the old vector g0 would not implement gradient descent at that point.
    🔗
    🔗
  4. With \(\alpha=1\text{,}\) the new point is \((-2,-5)\) and \(f(-2,-5)=20\text{,}\) an increase from \(0\text{.}\) The local model predicts a change of \(-29\text{,}\) but this larger step goes too far for that prediction to ensure a decrease. A negative-gradient direction does not guarantee a decrease for every positive learning rate.
