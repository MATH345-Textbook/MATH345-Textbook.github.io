Algorithm 2.4.8. A Test of Independence.

To verify if a set \(\{ \mathbf{x}_1,\dots,\mathbf{x}_k \}\) in \(\R^n\) is linearly independent:
  1. Consider the system of linear equations \(t_1 \mathbf{x}_1 + \cdots + t_k \mathbf{x}_k = \mathbf{0}\text{.}\)
    🔗
  2. Solve the resulting homogeneous linear system.
    🔗
  3. If there is a nontrivial solution to the equation, then the vectors are linearly dependent. Otherwise, the vectors are linearly independent.
