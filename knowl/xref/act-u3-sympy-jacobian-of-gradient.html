Activity 3.3.43. Checking the Jacobian of a gradient in SymPy (U3-LO3).
The command F.jacobian([x, y]) differentiates each component of a SymPy column matrix F. Rows follow the component order in F; columns follow the variable order [x, y]. Compare the scalar-valued function \(f(x,y)=3x^2y+2x-3y\) with its vector-valued gradient.
🔗
import sympy as sp

x, y = sp.symbols("x y")
f = 3*x**2*y + 2*x - 3*y
grad_f = sp.Matrix([sp.diff(f, x), sp.diff(f, y)])
J_f = sp.Matrix([f]).jacobian([x, y])
J_grad = grad_f.jacobian([x, y])
H = sp.hessian(f, (x, y))

print(J_f)
print(J_grad)
print(J_grad - H)
Output:
🔗
Matrix([[6*x*y + 2, 3*x**2 - 3]])
Matrix([[6*y, 6*x], [6*x, 0]])
Matrix([[0, 0], [0, 0]])
  1. Why does J_f have one row, while J_grad has two? Give the input and output dimensions of each map.
    🔗
    🔗
  2. How is J_f related to grad_f? Interpret the first row and the second column of J_grad.
    🔗
    🔗
  3. What identity does the zero matrix verify? Is this a comparison at one point or a symbolic comparison for this polynomial?

Solution.
The map \(f:\R^2\to\R\) has one component, so \(J_f\) has shape \(1\times2\text{.}\) The map \(\nabla f:\R^2\to\R^2\) has two components, so \(J_{\nabla f}\) has shape \(2\times2\text{.}\) The scalar Jacobian is the transpose of the gradient: \(J_f=(\nabla f)^T\text{,}\) represented by grad_f.T.
🔗
The first row of \(J_{\nabla f}\) differentiates the first component \(f_x=6xy+2\) with respect to \(x\) and \(y\text{.}\) Its second column differentiates both components with respect to \(y\text{.}\) These give the row \(\begin{bmatrix}6y&6x\end{bmatrix}\) and the column \(\begin{bmatrix}6x\\0\end{bmatrix}\text{,}\) respectively.
🔗
The zero difference verifies \(J_{\nabla f}=H_f\) for this polynomial. No point was substituted: every entry of the symbolic difference is zero for all \((x,y)\in\R^2\text{.}\)
