Theorem 2.4.45. Computing rank by row reduction.

The rank of a matrix \(M\) is the number of pivots in any row echelon form row equivalent to \(M\text{.}\)
🔗
🔗

Why is this true?.

By Note 2.4.37, the pivot count equals \(\dimens(\row(M))\text{,}\) which is \(\rank(M)\) by Definition 2.4.42.
