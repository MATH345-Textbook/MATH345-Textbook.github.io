Definition 1.3.37. Affine map.

Let \(A\) be an \(m\times n\) real matrix and let \(\mathbf{b}\in\mathbb R^m\) be a fixed column vector. The function
\begin{equation*} F:\mathbb R^n\to\mathbb R^m,\qquad F(\mathbf{x})=A\mathbf{x}+\mathbf{b}, \end{equation*}
where \(\mathbf{x}\in\mathbb R^n\) is a column vector, is called affine. It is built from a linear map followed by a translation.
